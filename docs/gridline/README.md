# Gridline shared assets

Adapted from the user-supplied Gridline Design System.zip, September 9, 2026.
The token files and logo SVGs come from that package. `gridline.css` and
`legacy.css` implement the project network's production layouts.

Canonical source and maintenance notes:
[thereprocase.github.io / GRIDLINE.md](https://github.com/thereprocase/thereprocase.github.io/blob/main/GRIDLINE.md).

Keep square corners, System Gray structure, white content fields, Active Blue
pane titles, IBM Plex Sans and Mono, visible navigation and status bars.
Use cyan for linked/live records and amber for qualification notes. Preserve
scientific image and plot colors. Do not add gradients, shadows, pills or emoji.
